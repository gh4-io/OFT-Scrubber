# OFT Scrubber v0.1.1

A standalone Windows tool that fills Outlook template variables and produces a completed HTML
email as a draft. This release replaces v0.1.0.

## What it does

- Open Outlook `.oft` templates (and `.msg` messages) by dialog, command line, or by dropping
  the file anywhere on the window, including the preview.
- Detect `{{Name}}`, `[[Name]]`, `${Name}`, `<<Name>>`/`«Name»` and `%%Name%%` tokens in the
  subject, HTML body, links, plain body and recipients. Repeated or differently written tokens
  with the same name become one field.
- Give each variable a type: text, date, time, date and time, number, web link or email. The
  type is guessed from the name and can be changed per field.
  - Dates: calendar picker or typed input (`2026-09-21`, `21 Sep 2026`, `21SEP26`, `today`),
    written as `21 Sep 2026`, `September 21, 2026`, `Monday, September 21, 2026`, `09/21/2026`,
    `21/09/2026`, `2026-09-21` or `21SEP26`.
  - Times: `1430`, `14:30`, `2:30 pm` or `now`, written as `14:30`, `1430` or `2:30 PM`.
  - Numbers with or without thousands separators; text as entered or in uppercase.
  - Web links and email addresses as clickable links (optional text to show) or plain text.
    Only http, https and mailto links are produced.
  - Each field shows what the email will say, or why a value cannot be used.
- Replace only the token text: the original HTML, styles, tables, links and inline images are
  kept as they are. Values are escaped for their context.
- Preview the subject, recipients, attachments and rendered HTML with scripts, plug-ins,
  network access and link navigation switched off. Inspect the exact HTML and parser details.
- Save an `.eml` draft, or open it in the default mail app to review and send. Nothing is sent
  automatically.
- Single executable targeting .NET Framework 4.8, with no runtime packages to distribute.

Download and run OftScrubber.exe on Windows. It is unsigned, so downloaded copies may trigger a
Windows security prompt. The app stores no settings; variable types are guessed again each time
a template is opened.

The repository contains no sample emails. No distribution license has been selected.

## Known limits

Validated against a small number of real templates so far. Templates whose body exists only as
rich text without HTML lose formatting (reported in the app). Embedded Outlook items and OLE
objects are not carried into the draft (reported in the app). The preview uses the Windows
WebBrowser engine, which can differ slightly from Outlook's rendering. Dates and times are
written with English month and day names.

## Validation

Release build with no warnings, core regression checks (variable detection, typed formatting
and validation, link rendering, draft structure, preview sanitizing, script blocking in the
preview host), a real-template smoke test, About version check, and manual checks of the type
and format menus, calendar, time entry and whole-window drag and drop.
